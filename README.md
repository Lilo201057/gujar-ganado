# GUJAR Ganado
Prototipo V1 offline-first para control de ganado de ceba.

## V1
- Registro manual de número visual, RFID y peso
- Inventario local
- Pesajes e historial
- Cálculo de GMD
- Funciona offline después de la primera carga

Pendiente: Bluetooth SPP, báscula, sincronización central, OneDrive/Excel, usuarios, sanidad y salidas.
